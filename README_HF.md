# Bookvice

> จองง่าย ได้ครบ จบที่เดียว

แพลตฟอร์มจองคิวออนไลน์ — บริการความงาม สนามกีฬา และส่งของด่วน
จัดทำเป็นโปรเจกต์รายวิชา **89033167 Web Application Development**

เอกสาร API แบบโต้ตอบได้ที่ **[/docs](docs)**

## ความสามารถ

**ระบบจองสองแบบ**
- **แบบเลือกเวลา** — ดูช่องเวลาว่างจริงที่คำนวณจากตารางงานของแต่ละคน/แต่ละคอร์ท
- **แบบเรียกทันที** — บริการส่งของด่วน ไม่ต้องเลือกวันเวลา คิดค่าบริการตามระยะทาง

**สิ่งที่ระบบคิดให้จริง**
- ช่องเวลาว่างคำนวณจากวันทำงาน เวลาเข้า-ออก และคิวที่ถูกจองไปแล้ว
- รองรับร้านที่เปิดคร่อมเที่ยงคืนและเปิด 24 ชั่วโมง
- จำนวนคิวที่รับพร้อมกันนับจากคนที่เข้างานวันนั้นจริง
- ค้นหาร้านใกล้ตัวด้วยสูตร haversine คำนวณในฐานข้อมูล
- รีวิวเขียนได้เฉพาะผู้ที่ใช้บริการเสร็จแล้ว และเขียนได้ครั้งเดียวต่อการจอง

**เทคโนโลยี** — FastAPI · SQLAlchemy 2.0 · PostgreSQL · Pydantic v2 · JWT · Pillow · Leaflet

## หมายเหตุ

- ข้อมูลร้าน รีวิว และชื่อสถานที่ทั้งหมด**เป็นข้อมูลตัวอย่างเพื่อการสาธิต**
- การชำระเงินเป็น**การจำลอง** ไม่มีการตัดเงินจริงและไม่ต้องกรอกข้อมูลบัตรใด ๆ
- รูปที่อัปโหลดจะหายเมื่อ Space รีสตาร์ต เพราะใช้พื้นที่ชั่วคราว
