# User Journey → Source Code Mapping — GlowGo

เอกสารนี้แสดงว่า **User Journey Map** แต่ละขั้น ถูกแปลงเป็นหน้าจอและโค้ดอย่างไร

**Persona:** "มายด์" 25 ปี พนักงานออฟฟิศงานยุ่ง อยากจองบริการดูแลตัวเองสะดวก ๆ ต้องการร้านที่ไว้ใจได้ ราคาชัดเจน จองง่ายในที่เดียว

---

## ตารางแมป journey กับระบบ

### ขั้นที่ 1 — ค้นพบ (Discover) · อารมณ์: อยากรู้ อยากลอง
- **หน้าจอ:** `index.html`
- **สิ่งที่ผู้ใช้ทำ:** เข้าหน้าแรก เห็นหมวดบริการ ร้านแนะนำ
- **Pain point เดิม:** ไม่รู้ว่าเว็บช่วยอะไร / ไม่รู้ร้านไหนน่าเชื่อถือ
- **แก้ด้วย:** hero message ชัด, การ์ดหมวดบริการ, ร้านเรตติ้งสูง + ป้าย "รับรองสะอาด"

### ขั้นที่ 2 — สมัคร / เข้าสู่ระบบ · อารมณ์: ใจร้อน
- **หน้าจอ:** `pages/login.html`, `pages/signup.html`
- **สิ่งที่ผู้ใช้ทำ:** สมัคร / ยืนยัน / เข้าสู่ระบบ
- **Pain point เดิม:** ฟอร์มยาวเกินไป, OTP มาช้า
- **แก้ด้วย:** ปุ่มล็อกอิน Google / LINE (ลดขั้นตอน), ฟอร์มขอเฉพาะข้อมูลจำเป็น

### ขั้นที่ 3 — ค้นหา & เลือกบริการ · อารมณ์: สนใจจดจ่อ
- **หน้าจอ:** `pages/search.html`, `pages/shop.html`
- **สิ่งที่ผู้ใช้ทำ:** ค้นหา กรอง เทียบร้าน ดูโปรไฟล์ & รีวิว
- **Pain point เดิม:** ผลค้นหาไม่ตรง, ไม่มีราคา/รีวิวจริง
- **แก้ด้วย:** ค้นหา + ฟิลเตอร์ (หมวด/โซน/ราคา/เรตติ้ง), รีวิว "ยืนยันแล้ว", ราคาชัด, ตรารับรองความสะอาด

### ขั้นที่ 4 — จอง & ชำระเงิน · อารมณ์: กังวล (Moment of Truth)
- **หน้าจอ:** `pages/booking.html`
- **สิ่งที่ผู้ใช้ทำ:** เลือกวัน-เวลา กรอกรายละเอียด จ่ายมัดจำ
- **Pain point เดิม:** ขั้นตอนจองเยอะ, จ่ายพลาด, กลัวโดนเท/ไม่มาตามนัด
- **แก้ด้วย:** จองจบหน้าเดียว (stepper), เลือก slot ที่ว่างจริง, **คุ้มครองมัดจำ**, แสดงราคา/มัดจำ/ยอดคงเหลือชัดเจน

### ขั้นที่ 5 — หลังใช้บริการ / ซ้ำ · อารมณ์: ประทับใจ
- **หน้าจอ:** `pages/account.html`
- **สิ่งที่ผู้ใช้ทำ:** รับแจ้งเตือน เช็กอิน รีวิว จองซ้ำ
- **Pain point เดิม:** ไม่มีข้อมูลดูแลหลังใช้, ติดต่อร้านยาก, ลืมร้านเดิม
- **แก้ด้วย:** ประวัติการจอง, **แต้มสะสม** (จูงใจกลับมาใช้), เขียนรีวิวได้ทันที, ปุ่ม "จองซ้ำ" ร้านเดิม

---

## Key Insight ที่นำมาออกแบบ
> อารมณ์ดิ่งต่ำสุดช่วง **"จอง & ชำระเงิน" (กังวล = Moment of Truth)**
> แก้ด้วย: คุ้มครองมัดจำ + ราคา/รีวิวจริง + ตรารับรองความสะอาด
> จุดขาย: รวมทุกบริการสุขภาพ & ความงามไว้ที่เดียว จองง่าย ไว้ใจได้

โค้ดจึงเน้นความโปร่งใสของราคาและความมั่นใจในขั้นตอนจอง (`booking.js`) มากเป็นพิเศษ โดยแสดงยอดมัดจำ ยอดคงเหลือ และข้อความคุ้มครองอย่างชัดเจน
