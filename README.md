## ฟีเจอร์หลัก (แมปกับ User Journey 5 ขั้น)

| ขั้นของ Journey | หน้าจอ | ฟีเจอร์ที่ทำ |
|---|---|---|
| 1. ค้นพบ (Discover) | `index.html` | Landing, หมวดบริการ, ร้านแนะนำ |
| 2. สมัคร/เข้าสู่ระบบ | `pages/login.html`, `pages/signup.html` | ล็อกอิน Google/LINE (mock), ฟอร์มสั้น |
| 3. ค้นหา & เลือกบริการ | `pages/search.html`, `pages/shop.html` | ค้นหา+กรอง+จัดเรียง, โปรไฟล์ร้าน+รีวิว+ราคา |
| 4. จอง & ชำระเงิน | `pages/booking.html` | จองจบหน้าเดียว, เลือกเวลา, มัดจำ 30% + คุ้มครอง |
| 5. หลังใช้บริการ / ซ้ำ | `pages/account.html` | ประวัติจอง, แต้มสะสม, เขียนรีวิว, จองซ้ำ |

> แต่ละหน้ามีป้าย "อารมณ์" (emotion tag) กำกับตาม journey เพื่อโยงดีไซน์กับ pain point ที่ต้องแก้

### ฟีเจอร์เสริม (ยกระดับประสบการณ์)
- 🌙 **Dark mode** — ปุ่มสลับธีมกลางวัน/กลางคืนบน navbar จำค่าไว้ข้ามหน้า/รีเฟรช
- ❤️ **รายการโปรด (Favorites)** — กดหัวใจที่ร้านไหนก็ได้ มีตัวกรอง "เฉพาะโปรด" และรวมร้านโปรดในหน้าโปรไฟล์
- ⭐ **รีวิว + ให้ดาวจริง** — เขียนรีวิวพร้อมเลือกดาว (1–5) ในหน้าร้าน แสดงผลทันทีและคำนวณคะแนนเฉลี่ยใหม่
- 📊 **แดชบอร์ดสถิติ** — สรุปจำนวนการจอง ยอดชำระรวม แต้มสะสม และจำนวนร้านโปรด
- 🎁 **แลกแต้มเป็นส่วนลด** — ใช้แต้มสะสมลดค่ามัดจำตอนจอง
- 🕒 **ดูล่าสุด** — จำร้านที่เพิ่งเข้าชมมาแสดงในหน้าแรก
- 🔍 **ช่องค้นหาบน hero** + ค้นหาจากชื่อ/หมวด/โซน

### ดีไซน์
สไตล์ **Glassmorphism** — การ์ดกระจกเบลอโปร่งแสง, พื้นหลัง gradient blobs เคลื่อนไหว, ปุ่มไล่เฉดสี, animation ตอนโหลด รองรับทั้งโหมดสว่างและมืด

## Tech Stack

- **HTML5** — โครงสร้างหน้า (multi-page)
- **CSS3** — สไตล์ล้วน ไม่พึ่ง framework (ใช้ CSS variables, Flexbox, Grid, responsive)
- **Vanilla JavaScript (ES6+)** — ตรรกะทั้งหมด ไม่พึ่ง library ภายนอก
- **localStorage** — จำลอง session / ฐานข้อมูลฝั่ง client (auth, การจอง, แต้ม)

ดูรายละเอียดและเหตุผลการเลือกใน [`docs/TECH_STACK.md`](docs/TECH_STACK.md)

## ทดลองใช้งาน (flow แนะนำ)
1. เปิดหน้าแรก → เลือกหมวด เช่น "สปา"
2. กรอง/เรียงร้าน → กดเข้าร้าน → ดูรีวิว & ราคา
3. กด "จองคิว" → ระบบให้เข้าสู่ระบบก่อน (กด Google/LINE ได้เลย)
4. เลือกบริการ + วัน-เวลา → จ่ายมัดจำ
5. ไปหน้า "การจองของฉัน" → ดูแต้มสะสม เขียนรีวิว หรือจองซ้ำ
